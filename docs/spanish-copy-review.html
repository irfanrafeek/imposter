Spanish copy, side by side with the English

Every Spanish string in the three Impostor games, next to the English it was written from. 827 entries: 661 in-game strings and 133 pieces of landing-page copy. The Spanish launched today, so nothing here has been read by a native speaker yet. That is what this document is for.

What we are asking

Not “is this correct?” Correct is the easy bar and it already clears it. The useful questions are:

  1. Does anything read translated? The interface was written in Spanish rather than translated from English, and the thing to catch is where that slipped.
  2. Does anything sound like it is from somewhere else? A word, a verb form or a turn of phrase that places the text in a country that is not yours.
  3. Would you say it this way to friends? This is a party game. Copy that is technically right but stiff is still wrong.

Reading from two regions is the point rather than a nicety. The Spanish was written to be neutral, so the test is that it sits badly with neither Latin America nor Spain, and one reader can only speak for their own half.

The rules the Spanish was written against

Worth knowing before you read, because most of these were decisions rather than accidents. If one of them is wrong, that is the most useful thing you can tell us.

  • No vosotros. Third person for anything descriptive (todos juegan), which is identical everywhere, and the ustedes imperative only for real commands (empiecen). Tú stays when speaking to one player.
  • No vocabulary that splits by country. teléfono not móvil or celular; error not fallo; atrapar not pillar.
  • Simple past, not present perfect. no se pudo reads normally everywhere; no se ha podido marks the text as Spanish from Spain.
  • Three coined terms we are least sure of: auriculares for headphones, ir a otro ritmo for the impostor being off-vibe, and una lista de canciones for a saved song group. Also Maestro del Juego, which is new and had no precedent.

How to send feedback

Every row has an ID such as DAN-042. Quote the ID and say what you would change. A companion spreadsheet with the same IDs and two empty columns is available if you prefer to type straight into one.

Not included here: the word and drawing catalogues (550 Spanish words with 1,100 hints, and 350 drawing words). Those need a different kind of read and will come separately.
